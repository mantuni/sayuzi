# 사유지 거닐기

사유지 앱의 '거닐기'를 데스크탑 3D 공간으로 넓힌 전시용 사이트.

- `index.html` 한 장으로 돌아감 (three.js는 CDN에서 불러옴)
- 웹앱과 같은 수파베이스(`kdkltisuuplmepwjroch`)를 씀. 주소·공개 키는 `index.html` 맨 위 `CONFIG`
- 처음 한 번: `supabase-geonilgi.sql`을 수파베이스 SQL Editor에 붙여넣고 Run

## 웹앱과 이어지는 방식
- 웹앱 거닐기에 늘 있는 필지 14곳 + 예시 필지 1013은 웹앱 코드의 데이터를 그대로 옮겨 둠
- 웹앱에 로그인한 사람의 필지는 `geonilgi()` 함수로 4초마다 확인
  - 새로 가입해 기록이 저장되면 새 필지가 땅에서 솟아오름
  - 생각을 쓰면 그 필지에 생기고, 고치면 고쳐지고, 묻거나 지우면 사라짐
  - 웹앱에서 다른 필지에 남긴 네모·한 줄 흔적도 그 생각 카드에 보임
- 묻은 생각, 이메일, 초안, '나는' 요약, 사진은 함수 밖으로 나오지 않음
- 로그인하지 않고 둘러보기로 쓴 기록은 그 기기에만 있어서 거닐기에 안 나옴

조작: 마우스 드래그로 둘러보기, 휠로 확대, 방향키·WASD로 걷기, Space 점프, V 1·3인칭, M 전체 땅, Q 표정 흔적.
